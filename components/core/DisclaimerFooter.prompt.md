The sponsorship disclaimer footer — required on every page, template, and piece built with this system. This is what keeps unbranded patient content compliant: no device name, logo, or claim appears anywhere else in the piece, and this is the one line that discloses sponsorship.

```jsx
<DisclaimerFooter />
<DisclaimerFooter text="Sponsored by [confirmed entity name]." />
<DisclaimerFooter onDark text="Sponsored by [confirmed entity name]." />
```

**Do not invent or approve disclaimer wording.** The default `text` is a visible placeholder on purpose — get exact required wording from Legal/Regulatory before publishing anything external. This component (and this design system generally) is not a substitute for MLR review.
